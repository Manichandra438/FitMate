## What AI learned that isn't in docs yet
- Emulator tap coords require `uiautomator dump` — React Native views inside ScrollView don't expose proper bounds to UIAutomator; use regex to parse XML
- `keyevent 4` from a main tab exits the app (Android back behavior) — avoid pressing back from tabs
- Screenshot tool rejects images >~1MB; need to resize to 540px wide using `System.Drawing` on Windows
- Expo dev build shows debugger banner at bottom — can intercept taps; dismiss with X at ~(1040, 2182)
- `show_ime_with_hard_keyboard 1` required for soft keyboard to show in emulator (hardware keyboard suppresses it)

## Errors hit + how they were fixed
| Error | Root cause | Fix |
|-------|-----------|-----|
| JSX parse error "Expected closing tag for ScrollView" | Metro bundled partial edit mid-session | Complete all edits, restart Metro |
| Screenshot "media removed — rejected by API" | Image too large (1080×2400 PNG) | Resize to 540×1170 using System.Drawing |
| UIAutomator bounds `[0,0][1080,2400]` | ScrollView children don't expose bounds | Parse raw XML with regex instead |
